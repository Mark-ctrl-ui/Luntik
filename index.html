1️⃣ HTML — створення структури сайту

HTML створює основу сторінки.

Базова структура

<!DOCTYPE html>
<html>
<head>
    <title>Мій сайт</title>
</head>
<body>

    <h1>Заголовок</h1>
    <p>Текст сторінки</p>

</body>
</html>

Приклад з картинкою та посиланням

<h2>Про сайт</h2>

<img src="image.jpg" width="200">

<a href="https://google.com">
    Перейти на сайт
</a>

2️⃣ CSS — оформлення сайту

Зміна фону і тексту

<style>
body {
    background:black;
    color:white;
}

h1 {
    color:cyan;
}
</style>

Стиль кнопки

button {
    background:blue;
    color:white;
    padding:10px;
    border-radius:5px;
}

3️⃣ JavaScript — логіка і дії

Приклад кнопки з повідомленням

<button onclick="showMessage()">Натисни</button>

<script>
function showMessage(){
    alert("JavaScript працює!");
}
</script>

Зміна тексту на сторінці

<p id="text">Старий текст</p>
<button onclick="changeText()">Змінити</button>

<script>
function changeText(){
    document.getElementById("text").innerHTML = "Новий текст";
}
</script>

4️⃣ Lua — початок написання скриптів

Перша програма

print("Hello, Lua!")

Змінні

number = 10
text = "Привіт"

print(number)
print(text)

Умова

score = 50

if score >= 60 then
    print("Зараховано")
else
    print("Не зараховано")
end

Цикл

for i = 1, 5 do
    print(i)
end

Функція

function add(a, b)
    return a + b
end

result = add(5, 3)
print(result)

Приклад для MoonLoader

script_name("Example Script")

function main()
    while true do
        wait(0)
        printStringNow("Скрипт працює", 1000)
    end
end
